## ProfileRepository

### `Create(ctx, params)`

Создаёт профиль и возвращает его без хэша пароля. Выполняет один `INSERT`. Ошибка уникальности преобразуется в `ErrProfileConflict`.

Ошибки: `ErrProfileConflict`, ошибка базы данных.

### `ReadByID(ctx, id)`

Возвращает активный профиль по ID. Удалённые профили не возвращаются.

Ошибки: `ErrProfileNotFound`, ошибка базы данных.

### `ReadByLoginAuth(ctx, login)`

Ищет пользователя по nickname, email или телефону (nickname, email, номер - гарантировано уникальные, следственно не может быть такого что пользователь хотел по нику, а база нашла совпадение в email или телефоне). Возвращает профиль и хэш пароля для авторизации. Хэш не входит в публичную часть профиля.

Ошибки: `ErrProfileNotFound`, ошибка базы данных.

### `Update(ctx, id, params)`

Изменяет только поля, которые переданы в `params`. Если полей нет, возвращает текущий профиль. Выполняет один `UPDATE`. Удалённый или отсутствующий профиль приводит к `ErrProfileNotFound`, конфликт уникальных значений — к `ErrProfileConflict`.

Ошибки: `ErrProfileNotFound`, `ErrProfileConflict`, ошибка базы данных.

### `Delete(ctx, id)`

Выполняет soft-delete на профилем

Ошибки: `ErrProfileNotFound`, ошибка базы данных.

## SessionRepository (in-memmory)

Сессии сейчас хранятся в памяти процесса, поэтому транзакции базы здесь не используются.

### `Create(userID)`

Генерирует session-токен и CSRF-токен, сохраняет их вместе с ID пользователя и возвращает оба токена.

Ошибки: ошибка генерации случайного токена.

### `Read(token)`

Находит сессию по токену и возвращает ID пользователя и CSRF-токен. Для чтения используется `RLock`.

Ошибки: `ErrSessionNotFound`.

### `ValidateCSRF(token, csrfToken)`

Сравнивает переданный CSRF-токен с токеном из сессии через constant-time comparison.

Ошибки: `ErrInvalidCSRF`.

### `Delete(token)`

Удаляет сессию из памяти.

Ошибки: не возвращает ошибок.

## AvatarRepository

### `Create(ctx, profileID, request)`

Использует транзакцию базы и advisory lock профиля. Внутри проверяет существование профиля и текущее количество активных аватарок. При ошибке транзакции временный файл удаляется.

Ошибки: `ErrInvalidAvatar`, `ErrProfileNotFound`, `ErrAvatarLimit`, `ErrAvatarNotFound`, ошибка файловой системы, ошибка базы данных.

### `List(ctx, profileID)`

Возвращает активные аватарки профиля от новой к старой. Использует один запрос.

Ошибки: `ErrProfileNotFound`, ошибка базы данных.

### `Delete(ctx, profileID, avatarID)`

Находит аватарку профиля и мягко удаляет связь с профилем и запись медиа. Обе операции выполняются в одной транзакции.

Ошибки: `ErrAvatarNotFound`, ошибка базы данных.

## PostRepository

### `Create(ctx, params)`

Создаёт публикацию и загружает данные автора. Один `INSERT` и дополнительные запросы для автора.

Ошибки: `ErrInvalidPostAuthor`, `ErrPostNotFound`, ошибка базы данных.

### `ReadByID(ctx, id)`

Возвращает активный пост вместе с автором и медиа. Если пост удалён или отсутствует, возвращает `ErrPostNotFound`.

Ошибки: `ErrPostNotFound`, ошибка базы данных.

### `ReadProfilePosts(ctx, profileID, cursor, limit)`

Возвращает страницу постов указанного пользователя в порядке от новых к старым. Автор и медиа подгружаются пачкой.

Ошибки: `ErrProfileNotFound`, ошибка базы данных.

### `ReadFeedPosts(ctx, cursor, limit)`

Возвращает страницу общей ленты в порядке от новых постов к старым. Данные авторов и медиа загружаются пачкой.

Ошибки: ошибка базы данных.

### `Update(ctx, id, params)`

Изменяет текст активного поста. Если поля для изменения не переданы, возвращает текущий пост. Выполняет один `UPDATE`.

Ошибки: `ErrPostNotFound`, ошибка базы данных.

### `Delete(ctx, id)`

Помечает пост удалённым через `deleted_at`. Если обновлена нулевая строка, возвращает `ErrPostNotFound`.

Ошибки: `ErrPostNotFound`, ошибка базы данных.

## ChatRepository

### `Create(ctx, profileID, otherProfileID)`

Создаёт личный чат или возвращает уже существующий. В одной транзакции:

- ставит advisory lock для пары пользователей;
- проверяет существование профилей;
- ищет или создаёт чат;
- пачкой добавляет участников.

Это не позволяет одновременно создать два одинаковых личных чата.

Ошибки: `ErrProfileNotFound`, ошибка базы данных.

### `ListChats(ctx, profileID, cursor, limit)`

Возвращает чаты пользователя с курсорной пагинацией. Участники и последние сообщения загружаются пачками, поэтому запросы не выполняются отдельно для каждого чата.

Ошибки: `ErrProfileNotFound`, ошибка базы данных.

### `IsParticipant(ctx, chatID, profileID)`

Проверяет, что профиль является активным участником чата. Используется перед чтением сообщений.

Ошибки: `ErrNotChatParticipant`, ошибка базы данных.

## MessageRepository

### `Create(ctx, params)`

Сам открывает и завершает транзакцию. Внутри одной транзакции:

- проверяет участие автора в целевом чате;
- при репосте проверяет доступ автора к исходному сообщению;
- при ответе проверяет принадлежность исходного сообщения целевому чату;
- блокирует проверяемые строки через `FOR UPDATE`;
- вставляет новое сообщение.

При ошибке выполняется `Rollback`, при успехе — `Commit`. Это исключает ситуацию, когда проверка прошла, но до вставки исходное сообщение или участие пользователя изменились.

Ошибки: `ErrNotChatParticipant`, `ErrRepostForbidden`, `ErrReplyForbidden`, `ErrMessageNotFound`, ошибка базы данных.

### `ListMessages(ctx, chatID, cursor, limit)`

Возвращает страницу сообщений чата и активные родительские сообщения для `reply_from` и `repost_from`. Основные сообщения и родители загружаются пачками.

Ошибки: `ErrChatNotFound`, ошибка базы данных.

## RelationshipRepository

### `Create(ctx, profileID, request)`

Создаёт запрос на связь. В транзакции с advisory lock пары пользователей проверяет существование профилей, ищет активную связь и запрещает вторую активную связь между той же парой. Отменённая связь может быть переиспользована.

Ошибки: `ErrInvalidRelationship`, `ErrProfileNotFound`, `ErrRelationshipConflict`, `ErrRelationshipNotFound`, ошибка базы данных.

### `List(ctx, profileID, request)`

Возвращает связи пользователя с фильтрацией по статусу и типу, курсорной пагинацией и кратким профилем второй стороны.

Ошибки: `ErrProfileNotFound`, ошибка базы данных.

### `Requests(ctx, profileID, type, cursor, limit)`

Возвращает входящие запросы на связь указанного типа.

Ошибки: `ErrProfileNotFound`, ошибка базы данных.

### `Types(ctx, profileID)`

Возвращает типы активных связей пользователя.

Ошибки: `ErrProfileNotFound`, ошибка базы данных.

### `Suggestions(ctx, profileID, cursor, limit)`

Находит возможные связи через общих знакомых. Кандидаты сортируются по количеству общих связей, уже существующие прямые связи исключаются. Данные профилей загружаются пачкой.

Ошибки: `ErrProfileNotFound`, ошибка базы данных.

### `Accept(ctx, profileID, request)`

Переводит входящий запрос указанного типа в подтверждённую связь. Если подходящего активного запроса нет, возвращает ошибку.

Ошибки: `ErrInvalidRelationship`, `ErrRelationshipNotFound`, ошибка базы данных.

### `Cancel(ctx, profileID, request)`

Переводит исходящий запрос или активную связь в состояние отменённой.

Ошибки: `ErrInvalidRelationship`, `ErrRelationshipNotFound`, ошибка базы данных.
